# ShareShed — Campus Resource Sharing Platform

**Share more. Waste less. Learn together.**

## About the Project
ShareShed is a campus resource-sharing platform concept that helps students discover and request shared resources, such as equipment and study facilities.

## Problem Statement
Students may struggle to find available campus resources. Manual booking and coordination can create confusion, while useful resources may remain underused.

## Proposed Solution
ShareShed provides a central platform where students can browse resources, submit booking requests, and track resource availability and returns.

## Key Features
- Search and browse campus resources
- Filter resources by category
- Submit booking requests
- View and manage booking statuses
- Demonstrate waiting lists and check-in
- Track returns and report incidents

## Technology Stack
- HTML
- CSS
- JavaScript
- Git and GitHub

## How to Run
1. Open or download this repository.
2. Open `prototype.html` in a modern web browser.
3. Explore the interface and test the available interactions.

## Project Status
This is a demonstration prototype. Some data and interactions are simulated. A production version would require secure authentication, a shared database, and backend services.

## Future Scope
