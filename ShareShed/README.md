# ShareShed – Campus Resource Sharing

Prototype built during CodeHack India 2026.

## Run in VS Code
1. Open VS Code -> File -> Open Folder -> choose the `ShareShed` folder.
2. Install the **Live Server** extension (Ritwick Dey) from the Extensions tab.
3. Right-click `index.html` -> **Open with Live Server**. The app opens in your browser.
   (No server needed: you can also just double-click `index.html`.)

## Files
- `index.html` – page structure
- `style.css` – all styling
- `script.js` – all app logic (data is saved in the browser's localStorage)
